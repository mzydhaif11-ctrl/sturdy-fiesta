# Mzyad OpenAI Cookbook Contributions

مستودع شخصي لتجربة وتوثيق المساهمات والتعديلات البرمجية المبنية على مشروع
[OpenAI Cookbook](https://github.com/openai/openai-cookbook).

## الهدف

يُستخدم هذا المستودع من أجل:

- تجربة أمثلة وأدوات الذكاء الاصطناعي.
- دراسة بنية المشاريع مفتوحة المصدر.
- توثيق التعديلات والمساهمات.
- التدريب العملي على Git وGitHub.
- إنشاء وتحسين ملفات التوثيق.
- اختبار Pull Requests وBranches وCommits.

## المحتويات

يتضمن المستودع أمثلة وملفات توثيق ومواد مرتبطة بالتجارب البرمجية، ومنها:

- `DOCUMENTATION.md` — توثيق العمل والتغييرات.
- `.github/` — إعدادات وملفات GitHub.
- `.codex/` — ملفات مرتبطة بالأدوات والمهارات.
- أمثلة ومقالات ومواد تعليمية.
- ملفات المساهمة والإرشادات الخاصة بالمشروع.

## المساهمة

أي تعديلات يتم تنفيذها في هذا المستودع يمكن اختبارها أولًا على فرع مستقل، ثم إرسالها عبر Pull Request عند الحاجة.

## المصدر

هذا المستودع مبني على Fork من:

`openai/openai-cookbook`

المشروع الأصلي مملوك ومُدار بواسطة OpenAI، وهذا المستودع يمثل تجارب ومساهمات شخصية مستقلة ولا يُعد مستودعًا رسميًا من OpenAI.
